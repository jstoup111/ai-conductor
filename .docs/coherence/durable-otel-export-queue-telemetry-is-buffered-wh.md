Criterion rows repeat the plan's `## Coverage Check` rows exactly: same criterion text, cited tasks and `Done when` quotes. An independent coverage judge passed all 52 of them on 2026-09-29, 6 of them after one revision round.

Consistency and achievability notes:
- **gRPC fallback vs gRPC unchanged.** Story 6's fallback criterion and its opt-out criterion share `buildExporters` for gRPC. Task 2 asserts unwrapped gRPC exporters in both configurations, and only the default one warns.
- **Leftover-spool warning vs preserved behavior.** Task 19's leftover-spool warning fires only when a spool directory is non-empty. The preserved scenarios (Story 6 opt-out, `exporter: file`, gRPC opt-out) assume no leftover spool, and Task 19 asserts no directory is created. The new side effect is therefore bounded to a condition those scenarios exclude.
- **Warnings on the failure path.** Task 6's once-per-exporter fallback warning (spool write failure) and Task 14's per-transition warning (delivery failure) fire on disjoint conditions. Story 1 criterion 4 and Story 2 criterion 4 each keep their "exactly one" bound.
- **Earlier feature's tests.** The existing unreachable-endpoint warning tests from the earlier daemon-dispatch OTel feature fire on the SDK export path, which the spool removes. Task 16's Steps re-point those tests to the drainer warning, and a companion main-based story PR updates that feature's criteria text. This plan edits no other feature's sealed artifact.
