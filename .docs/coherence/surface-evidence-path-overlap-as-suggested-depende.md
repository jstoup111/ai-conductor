**Plan:** `.docs/plans/surface-evidence-path-overlap-as-suggested-depende.md`

**Track:** product (Tier M). The change set has no `adr-*` file, so there is no `adr` row class. The governing APPROVED ADRs are cited by the architecture review.

## Outcomes

Outcome 1 (the overlap is surfaced before creation) is delivered by Stories 2, 3 and 4, which find the overlaps, and by Stories 9 and 10, which present them before any issue exists. Outcome 2 (accept gives a recorded link, decline gives an explicit decision) is delivered by Stories 9, 11 and 12. Recording an accepted link on GitHub also depends on #2714, which lands first (blocked_by link). Outcome 3 (no overlap behaves as today, with no added burden) is delivered by Story 8, and by Story 14, which ensures a failing check never blocks filing.
