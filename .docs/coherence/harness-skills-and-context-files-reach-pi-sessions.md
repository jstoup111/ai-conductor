## Notes

- **outcome-1.** Parity with claude/codex is split across Stories 1-4:
  - the skill command Pi expands (Story 1)
  - a visible refusal instead of an uninstructed chat (Story 2)
  - HARNESS.md in the system prompt (Story 3)

  The global `~/.agents/skills` catalog and `AGENTS.md`/`CLAUDE.md` context files already reach Pi natively (verified on pi 0.84.3), so they need no task.
- **outcome-2.** Story 6 covers acceptance, readiness, and idempotence. No new catalog wiring is needed, because Pi reads the `~/.agents/skills` links `bin/install` already creates.
- **outcome-5.** Story 6's catalog-listing criteria prove that the claude and codex links are untouched.
