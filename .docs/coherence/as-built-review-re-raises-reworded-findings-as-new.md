# Coherence: As-built review re-raises reworded findings as new obligations (#3127)

**Plan:** .docs/plans/as-built-review-re-raises-reworded-findings-as-new.md
**Stories:** .docs/stories/as-built-review-re-raises-reworded-findings-as-new.md
**Track:** technical, so there are no FR rows. **Tier:** M.
**Source-Ref:** jstoup111/ai-conductor#3127

One ADR is in this change set, `adr-2026-10-28-as-built-finding-reconciliation`, and all seven of
its decisions have rows in the plan's Architecture Obligation Coverage. This spec also changes two
existing story criteria, the existing-task owner-binding exception resolved by the conflict check;
they are story artifacts, not ADRs, and add no ADR row. This spec delivers every intake outcome, so
no waiver is needed. Outcome 3's "reopened" is delivered two ways: a `recurrence` restages the
prior repair task, and a `materially-changed` finding opens a linked case (Stories 3 and 4).
Outcome 4's "another gate's approval" is delivered by Story 5: build_review and PRD widening
records are never projected or used as as-built authority.
