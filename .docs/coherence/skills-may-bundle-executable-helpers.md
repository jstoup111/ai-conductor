## Architecture decisions

Each of the seven decisions in the ADR maps to a `task` disposition in the plan's Architecture Obligation Coverage table, and each cited Done-when check asserts its decision. D1: the helper under `skills/intake/scripts/` is executable through both hosts' discovery homes (task-8). D2: the helper hands off to the engine entry point with the arguments unchanged (task-1). D3: the skill names the helper relative to its own directory for both hosts (task-4). D4: resolution fails by name, never guesses (task-2, with the ancestor-walk and fallback cases in the same task). D5: the caller's working directory is preserved (task-1). D6: the shell-lint list includes the helper (task-5), and the interpreter-source inventory includes it too (task-7). D7: the git diff shows a delete plus an add, not a rename (task-4). No story contradicts a decision: Story 2 is D4's resolution order exactly, and Story 3 is D6's gate set.
