# Coherence: Enforce canonical code formatting on touched files (#1991)

**Plan:** .docs/plans/code-formatting-is-entirely-unenforced-no-formatte.md
**Stories:** .docs/stories/code-formatting-is-entirely-unenforced-no-formatte.md
**Track:** technical, so there are no FR rows. **Tier:** M. No ADR file is in the change set, so there are no ADR rows.
**Source-Ref:** jstoup111/ai-conductor#1991

Outcome 1 is delivered under the operator-confirmed scope boundary in `.docs/track/code-formatting-is-entirely-unenforced-no-formatte.md`: only files a change adds or modifies are checked, so a violating file fails CI when a pull request touches it. Untouched files are left to the operator's manual `npm run format -- --all` sweep.
