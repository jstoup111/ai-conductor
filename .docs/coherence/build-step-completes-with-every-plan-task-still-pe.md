# Coherence: BUILD cannot complete on stale task evidence

Source-Ref: jstoup111/ai-conductor#2014. Tier M, technical track (no PRD, so no `fr` rows).

Outcome mapping: outcome 1 (no success while tasks are pending) and outcome 2 (incomplete tasks named by id and title) are delivered by Story 2. Outcome 3 (a resumed build executes rewritten pending tasks; a remediation task alone does not satisfy the step) is delivered by Story 1, whose plan-change reopen is the root-cause fix, with the Story 2 remediation-only negative proving an appended task alone does not satisfy the step. Outcome 4 (a build with nothing left completes cleanly) is delivered by Story 3.

Consistency pass: no cross-layer contradiction. The reopen charges no lap (Task 4) while a `coverage_binding` reopen keeps its own lap (adr D10); the bounded single daemon retry line is unchanged while ids-first ordering (Task 10) keeps every id visible in it; the stall reason text stays byte-identical (Task 12).
