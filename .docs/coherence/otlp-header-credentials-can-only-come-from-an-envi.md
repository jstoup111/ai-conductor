## Architecture-decision tie-out (§4f)

- **D1** (shared module, parser and async value-or-unavailable resolver): Tasks 1 and 2 assert the parser's typed references and named non-throwing errors, and `resolve()` returning value or unavailable with no otel import.
- **D2** (env and command sources): Task 3 asserts `execFile` with the argument list, `shell: false`, `timeout: 10000` and a tmux-scrubbed environment, plus `~/` expansion, trimming and prefixing; Task 4 asserts the failure mapping, output exclusion and the `AI_CONDUCTOR_NO_REAL_EXEC` kill-switch.
- **D3** (TTL cache, single flight, failures uncached, env re-read): Task 5 asserts the 300-second and 60-second boundaries, one runner call for five concurrent resolutions, and no caching of a failure.
- **D4** (`otel.headers` consumer, load-time env refusal, send-time command resolution on both paths): Task 6 asserts config acceptance without running the command; Tasks 7 and 9 assert the spooled and direct requests carry the resolved header.
- **D5** (failed resolve blocks the send; `credential` reporting class; `lastFailureClass` unchanged): Task 8 asserts zero POSTs, the retained batch, one `renderer_error` per class transition and `lastFailureClass` still `network`; Task 9 asserts a FAILED direct export with no request and no unhandled rejection.
- **D6** (command references accepted from project config): Task 6 asserts `validateConfig` accepts a project-source config with a command header.
- **D7** (other consumers not migrated): `no-change` is correct; no task touches the bot-token, build-token or tracker code.

## Achievability (§4g)

Every criterion row's quoted check names the mechanism that produces its Then-clause (`parseCredentialReference`, `createCredentialResolver`, the production `execFile` runner, `resolveOtelConfig`, `validateConfig`, `createSpoolRuntime` and `SpoolDrainer`, `buildExporters`, the otel header provider) together with its observable assertion, and no cited check can pass while the criterion's outcome is absent. The only closed set involved, `otel_spool_backlog.lastFailureClass`, represents the required scenario truthfully: after a network warning a credential failure leaves it `network`. No criterion requires violating an approved decision. One binding assumption, ADR A2 (a rejected headers factory yields a failed export result), is operator-approved and is proven either way by Task 9's FAILED-result check.
