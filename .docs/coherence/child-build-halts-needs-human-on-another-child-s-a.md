# Coherence: Child BUILD halts needs-human on another child's already-resolved build-review case

Source-Ref: jstoup111/ai-conductor#3658. Tier M, technical track (no PRD, so no `fr` rows).

Outcome mapping: outcome 1 is delivered by Stories 1 to 4. A child's remediation inputs live in its own region (Story 1), the judgement is moved there and only prompt-named paths are readable (Story 2), settled inputs are deleted (Story 3), and files an older engine left at the feature level are adopted or removed (Story 4). Outcome 2 is Stories 5 and 6: a stall that cites only settled or foreign remediation state is answered by a BUILD re-dispatch with no remediation dispatch, and stops `mechanical` first. Outcome 3 is Story 6: the HALT names the existing `ai-conductor halt clear`, which clears it; the operator chose that command over a new one. Outcome 4 is the negative paths of Stories 1 and 5: an open owned case still reaches its child's BUILD prompt and still takes stall remediation.

Operator-approved bound on outcome 2 (2026-11-15): the outcome says the stall halts `mechanical` at worst. The daemon re-kicks `mechanical` halts without a bound, so a citation that persists would loop. The operator approved two in-run re-dispatches, then one `mechanical` HALT, then a `needs-human` HALT on the fourth consecutive stale citation of the same case with no task progress. Outcome 3 already anticipates that HALT and Story 6 gives it a supported clear.

Consistency pass: no cross-layer contradiction. Retirement (Story 3) deletes a region's work order only when its case store has no open case, so it never removes input an open owned case needs (Story 1 negative paths, Story 5 negative paths). The gap plan stays until its routed BUILD passes, so the prompt-named path of Story 2 is readable for the session it was routed to. The stale-citation branch runs before stall remediation and charges no round, so the budget of `adr-2026-07-10-daemon-stall-remediation` decision 6 is untouched.

Achievability pass: every criterion row cites Done-when checks asserted at the criterion's own layer (the conductor's dispatch prompt, stall seam, HALT, or event log). Tasks 1, 14 and 15 are lower-layer infrastructure whose behavior the conductor-level tasks 2, 16, 17, 18 and 19 carry to the entry point. No row depends on a state the closed stale-citation result set (`stale` resolved, `stale` foreign, `not-stale`) cannot represent.
