## Architecture decision judgement (§4f)

- **D1** (floors; escalation adds `gpt-6-astra`): task-2 asserts the floor grammar through resolution and task-3 asserts the four-rung escalation order with the fallback ladder unchanged.
- **D2** (tier-only catalog member): task-1 asserts `modelTierCatalog.argv` is `['debug', 'models']`, `modelCatalog` stays undefined, and the parser keeps only listed, API-supported slugs.
- **D3** (same tier, strictly newer, numeric segments): task-2 asserts terra stays `gpt-5.6-terra`, below-floor versions are ignored, and `6.10` beats `6.9`.
- **D4** (dispatching boot paths, once, timeout, never fails boot): task-5 asserts once-per-process probing and the three failure warnings; task-7 asserts all three boot paths run it and boot completes on each failure.
- **D5** (process registry; config overrides on top; floors elsewhere): task-2 asserts the registry-backed lookup and an unchanged descriptor policy; task-4 asserts configured ids win verbatim.
- **D6** (no new channel): task-8 asserts resolved ids on existing events, only pre-existing event types, and no file created.
- **D7** (unpriced warning; unmetered): task-6 asserts the exact once-per-id warning; task-8 asserts unmetered counting.
- **D8** (liveness alias): task-11 asserts `--model haiku` and no dated Claude id.
