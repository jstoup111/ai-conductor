## Outcome notes

- **outcome-1.** The judge's first verdict no longer halts: it is refused at validation and re-judged once with the refused binding named (story-2). A judgement that the finding is gone is answered with the existing evidence-backed refutation, which settles the case; the refute lane's evidence rules are unchanged by design (track scope boundary).
- **outcome-2.** Both halves are delivered: the context lists each prior case's bindable dispositions (story-1), and an inadmissible binding gets one bounded correction round before any halt (story-2).
- **outcome-3.** A binding outside the bindable set still fails closed after the bound (story-2, `case-R`, which has no applied effect), and the reconciler keeps its own `illegal-disposition-transition` backstop (story-3).
