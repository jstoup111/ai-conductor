## Consistency and achievability notes

- Preserved behaviour: Task 3 replaces the `projection-oversized` equality checks with a predicate; Story 4 negative paths bind that route and `provider-error` charging unchanged (Task 3 checks 4 and 5). Task 2 excludes non-contained invocations from the overlay (check 4), and Task 6 keeps built-in-only laps off the resolver (check 3).
- Daemon gate overlap: in a daemon run the daemon-level gate parks before build_review when the token is missing, so Story 4 is the fail-closed backstop for interactive runs and races (conflict report). Both hold; no oscillation.
- Cross-layer check (outcome to task): outcome 2 forbids reading host state beyond authentication; no task reads the operator stored login (Task 1 check 5) or writes into review scratch (Task 8 check 2).
