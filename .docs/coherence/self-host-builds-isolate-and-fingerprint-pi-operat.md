# Coherence: Self-host builds isolate and fingerprint Pi operator state

**Plan:** .docs/plans/self-host-builds-isolate-and-fingerprint-pi-operat.md
**Stories:** .docs/stories/self-host-builds-isolate-and-fingerprint-pi-operat.md
**Track:** technical (no fr rows). Outcomes come from the staged intake projection for jstoup111/ai-conductor#1887.

Outcome 4 maps to Story 2. Proven containment relaxes only the live-checkout surface, so an operator edit to fingerprinted Pi config halts a contained dispatch, exactly as an edit to Claude `settings.json` or Codex `config.toml` does today (adr D26). Story 2 negative 3 asserts this, and Task 6 checks it under a contained verdict.
