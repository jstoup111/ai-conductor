## Semantic assessment

The task checks deliver the full authorization chain: canonical actor and target resolution, committed ownership or request-specific authority, private transport composition, caller migration, and a production bypass audit. Missing evidence and unauthorized destinations refuse before mutation. Multi-ref Git writes are authorized as a complete destination set. Creation authority is limited to immediate metadata in the same transaction; source issues and shared repository resources require independent authority. Local Git behavior remains outside this change.

D8 resolves the historical conflict explicitly: foreign-resource notification writes are refused while local GATED state remains visible. Task 10 also preserves authorized upsert ordering and idempotency. The historical ADR is retained and superseded, not an instruction to restore foreign writes. Refusal event failures cannot authorize fallback writes or report false progress. Task dependencies supply the resolver, approval adapter, guarded transport, and CLI before their consumers. Faked external boundaries and the production invocation audit make these obligations testable within the implementation diff.
