## Judgement basis

The fresh coverage judge returned asserts for all 27 criteria. The tasks bind each check to a production boundary and implementation mechanism. Durable state pins actual Git commits, not only strings in JSON; shared acceptance is wired into both entry points; event retry precedes evidence retirement; reporting consumes persisted events. Prerequisite #3653 supplies correlation and the existing report. These are achievable design obligations, not claims that BUILD tests have run.

## Review refinements

Exact-parent reuse deliberately misses after a lower commit is re-stamped; the matching-parent story remains exact and gains a same-tree/different-SHA negative fixture. New helper modules use injected collaborators and type-only imports to avoid widening the existing cycle. Event dedup, original occurrence time and the completeness fixture are explicit Task 10 obligations. Pending-journal recovery is tested after durable acceptance but before child status advances. Task 8 consumes existing atomicity proof as verify-only; Tasks 6–7 own new acceptance-to-journal integration. Unresolved eligible source conflicts carry their original conflict context to bounded escalation. Invalid bookkeeping evidence stops with a validation error before provider dispatch. The operator approved this refinement after round 2 of plan review. These refinements strengthen the accepted checks without changing story outcomes.

## Outcome dispositions

outcome-1: Explicit rules and exact-context reuse, not every conceivable cheap resolution.

outcome-2: Unsupported apparently mechanical conflicts may reach the strong resolver.

outcome-3: Infrastructure or validation failures may halt without a design choice.

outcome-4: Resolution tiers extend the prerequisite event/reporting foundation.

outcome-5: Shortcut predicates reject known invalid candidates before apply; no universal semantic equivalence guarantee for arbitrary code.
