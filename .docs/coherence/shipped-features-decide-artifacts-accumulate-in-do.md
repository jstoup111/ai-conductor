# Coherence: Operator CLI prunes shipped features' DECIDE artifacts (#2963)

**Plan:** .docs/plans/shipped-features-decide-artifacts-accumulate-in-do.md
**Stories:** .docs/stories/shipped-features-decide-artifacts-accumulate-in-do.md
**Track:** technical, so there are no FR rows. **Tier:** M.
**Source-Ref:** jstoup111/ai-conductor#2963

Three ADRs are in this change set: the new governing ADR and the two on-main ADRs that carry #2963
amendment notes. Every decision of all three has a row in the plan's Architecture Obligation
Coverage (D1–D6, D1–D8, D1–D5). Every intake outcome is delivered by this spec, so no waiver is
needed. Outcome 1 is delivered through an operator-run command, the trigger the operator chose
for this spec (track scope boundary, ADR D2), rather than a daemon or finish-time sweep.
