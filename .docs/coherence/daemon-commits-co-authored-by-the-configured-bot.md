# Coherence: Daemon commits co-authored by the configured bot (#2722)

**Date:** 2026-09-28
**Tier:** M
**Track:** technical. The `fr` row class is omitted because there is no PRD; the stories carry the requirement layer.
**Outcome source:** jstoup111/ai-conductor#2722, four staged Desired-outcome bullets.

Outcome 1's avatar display and squash survival rest on GitHub behavior: the repository squash setting is `COMMIT_MESSAGES` (verified 2026-09-28), so branch-commit trailers reach `main`. The stories assert the trailer is a parseable trailer in the no-reply form (Stories 1–3). The ADR row cites the one ADR amended on the spec branch (adr-2026-09-11-github-operation-ownership D10). Story and task rows come from the plan's `**Story:**` lines, and criterion rows are generated from the same source as the plan's Coverage Check.
