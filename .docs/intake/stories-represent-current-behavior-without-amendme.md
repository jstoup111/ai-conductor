## Desired outcome

- A story artifact presents one unambiguous, current description of application behavior after a DECIDE correction.
- Correcting an accepted story replaces the superseded story content in place; the story itself contains no amendment-history record.
- Existing story artifacts remain usable and unambiguous after users upgrade to the release carrying this change.
- Amendment handling for other DECIDE artifact types is unchanged unless DECIDE separately establishes that their durable contract requires the same behavior.
