# Track: Let an operator park settle without a needs-human halt

Track: technical

Scope boundary: Small fix for #1803, approved by the operator on 2026-09-06 (delegated). Scope is the conductor's daemon-only markerless-exit backstop and its interaction with a boundary-settled operator park, plus proof that an unparked feature returns to ordinary selection and that a genuinely markerless exit keeps its existing needs-human halt. The park boundary's own dispatch semantics, the park CLI, the auto-park path, halt-class taxonomy, re-kick budgets, and the missing `.daemon/parked/<slug>` record the issue reports for one earlier 03:38 occurrence are outside this slice; that record gap is inferred in the issue itself and is not reproducible from the boundary-park path.

This is an internal daemon-orchestration defect fix; acceptance criteria live in technical stories rather than a PRD.

Approaches weighed on 2026-09-06 (delegated operator decision). **Chosen — exempt the backstop from a run that terminated at an operator park boundary.** The typed `OperatorParkedTermination` already exists and the daemon already classifies that outcome as `parked` without consulting markers, so the backstop is the only component still inferring an outcome it does not need to infer. **Rejected — write a distinct park-flavoured halt class the re-kick sweep treats as retryable** (the filer's second hypothesis): it still leaves a marker an operator or a later sweep must clear, and `isOperatorActionHalt` deliberately treats an unrecognized class as operator action, so a new class fails closed for every reader that has not been taught it. **Rejected — have unpark delete the halt marker**: unpark would then also erase a genuine needs-human halt that happened to be written before the park, destroying the one signal that says a human decision is owed.

Scope check: A — consumer-facing engine behavior. The daemon and its operator-park boundary ship in the installed engine and are documented for consumers under the daemon guide, so this is not self-host-only machinery; the repo-only "daemon machinery" reading of signal 1 is noted and rejected because the mechanism exists in every repository that runs the daemon. The change is a defect fix inside existing behavior: it adds no rule, no config key, no CLI surface, and no skill, so no `HARNESS.md` entry and no catalog registration follow. B — n/a (no new skill). C — provider-agnostic (no provider-specific code path is touched).

Verified foundation: `src/conductor/src/engine/conductor.ts` declares `stopAtOperatorParkBoundary` inside `run()`, emits the `operator_park_boundary` event, and returns `{ kind: 'operator-parked', boundary }` from five guarded dispatch sites; the same method's `finally` block writes a `needs-human` halt whenever a daemon run reaches it with neither the completion marker nor the halt marker, and that condition tests only `this.daemon` and the two markers. `src/conductor/src/engine/daemon-runner.ts` already short-circuits on `conductorTermination?.kind === 'operator-parked'` and returns `status: 'parked'` without reading any marker, and `src/conductor/src/engine/daemon.ts` parks the claim for that outcome so the ordinary halt/state checks govern resume. `pickEligible` in the same file re-admits a claim-parked slug only when its worktree halt check reports clear, which is exactly the state the spurious halt denies. `readHaltClass` and `isOperatorActionHalt` in `src/conductor/src/engine/halt-marker.ts`, consumed by `src/conductor/src/engine/daemon-rekick.ts`, retain `needs-human` unconditionally. `renderDashboard` in `src/conductor/src/engine/daemon-dashboard.ts` already filters parked slugs out of the halted group and renders every remaining halted slug with its reason and a clear-to-resume remedy, so the issue's fourth desired outcome is a verification, not new behavior. Existing coverage in `src/conductor/test/engine/operator-park-boundary.test.ts` drives a real daemon-mode `Conductor.run()` to a park termination but never asserts marker absence, and the acceptance suite's FR-5 case stubs the conductor entirely — so no test observes the defect today.
