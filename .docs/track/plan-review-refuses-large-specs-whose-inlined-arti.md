# Track: Plan review refuses Large specs whose inlined artifacts exceed 400k characters

Track: technical

Scope boundary: All four outcomes of the intake (operator confirmed 2026-10-24). `compose plan-review` runs for a Large spec whose plan, stories, coherence artifact and changed ADRs together exceed 400,000 characters and still reviews every task; the reviewer prompt no longer grows linearly with the full decision text of every cited ADR or with the coherence artifact; a remaining size refusal names each section's size, what to change, and the supported override; specs that fit today are reviewed with the same kinds of findings. Out of scope, filed as a separate follow-up intake: trimming duplication and extraneous content from the DECIDE artifacts themselves (for example the plan `## Coverage Check` rows repeated in the coherence artifact), which is a human-readability change to the `/plan` and `/coherence-check` contracts and parsers.

Internal engine behavior (the plan-review prompt assembly, its size refusal and its configuration), with no user-facing product requirements; acceptance criteria live in stories.

Chosen approach (A, with changed decisions inline): the prompt keeps the plan and stories verbatim, and keeps verbatim only the in-scope ADR decisions whose passage text differs from the spec's merge base, plus every decision of an ADR the spec adds. Every other in-scope decision, and the coherence artifact, is replaced by an index naming each item (`<adr-stem>#D<n>`, its title, and its worktree path) that the read-only reviewer opens with its own read tools. An operator override is added: a top-level `plan_review.max_prompt_chars` config key and a one-shot `--max-prompt-chars` flag on `compose plan-review`. This amends `adr-2026-10-10-source-grounded-adversarial-plan-review-step` D3, which lists every in-scope ADR decision section as an inline input. Architecture review (2026-10-24, operator confirmed) narrowed the inline rule from every decision of a changed ADR to changed decisions only: on #2945 every cited ADR was also a changed ADR (15 amended), so whole-ADR inlining kept all 141k characters of decision text, while changed decisions only measure 58k.

Rejected: (B) a budgeted tiered prompt that inlines in priority order and falls back to paths past the budget, because its tiering machinery rarely runs once the artifacts are trimmed, and the operator preferred the simpler projection; (C) sharding the review by task group, because separate reviewers cannot run the task-versus-task contradiction sweep across shards and the cost multiplies; making the cap configurable alone, because the prompt would still grow linearly with every cited ADR. Narrowing ADRs to only the decisions the plan cites was measured on the 11 plan-reviewed specs and removed 0-30% of the decision payload, so it is not sufficient on its own.
