# Track: Enforce module layering with the import-graph ratchet (#1988)

Track: technical

Scope boundary: Balanced. This spec is roadmap slice 2 of `adr-2026-10-07-conductor-decomposition-target-architecture`, and it delivers that ADR's D5 import-graph ratchet as written. The ratchet is a TypeScript-AST structural check over `src/conductor/src/` that runs in the default test tier, so it fails CI before merge. It enforces the chain `types ← execution ← engine ← ui ← entry`. It fails on any unlisted upward value edge and on any unlisted value edge that closes a cycle, and today's violations are allowlisted as one file per allowed edge. The allowlist can only shrink: an entry whose edge no longer exists, or is no longer a violation, fails the check. Edges are static value imports and value re-exports, classified syntactically; dynamic `import()` is not an edge. `conductor.ts` shim re-exports are modelled as ordinary edges. Excluded: any edit to `docs/contributing/code-organization.md`, and any doc-consistency check. The repository's `maintain-documentation` pre-finish gate refreshes that prose during the build, so the doc-drift outcome is waived to that gate. Also excluded: removing any existing violation, including the two #1017 violations (that is slice 3, `break-the-engine-ui-import-cycle-and-stop-types-im`, which depends on this ratchet); counting type-only edges or dynamic `import()` (slice 3 extends the upward rule to both); folding `checkConductorImports` or the `non-autonomy.test.ts` scanner into the ratchet (both stay as they are); any file-size or line-count budget (excluded by D5); any new dependency.

Rationale: D5 already fixes the mechanism, so this spec builds it as written. The operator removed the doc edit and doc check from this spec (2026-10-24), and `maintain-documentation` owns the doc refresh.
