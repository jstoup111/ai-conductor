Waives: skill symlink targets

Rationale: The path classifier flags `bin/install` as the skill-symlink-targets surface, but this change set does not alter which skill symlinks the installer creates or where they point. The install and `--update` paths are untouched; skill discovery and link creation are unchanged, and no file under `skills/` is added, removed, or renamed. The edits are confined to `--uninstall`: it now removes the harness hook commands and permissions it previously added to `~/.claude/settings.json`, removes the global rate-card link only when it points at this checkout, reports the preserved `~/.ai-conductor` state directory, and adds an opt-in `--purge` flag that removes that directory. The `--help` text moved into a shared `usage()` function with identical content plus the new flag. Existing installations keep working with no action after updating, so there is nothing for `bin/migrate` to run.
