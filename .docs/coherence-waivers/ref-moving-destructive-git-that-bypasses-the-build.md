Waives: outcome-1

Rationale: Outcome-1 names three ref-moving classes to refuse in a build worktree: force-deleting an unmerged branch, a non-fast-forward move of a branch ref, and a push that overwrites remote history without a lease. Stories 1 and 3 deliver the first and third, through the reference-transaction and pre-push hooks of adr-2026-09-23-engine-git-guard-on-agent-path decisions 12 and 13. The operator excluded local non-fast-forward branch moves during explore on 2026-10-03, because amend, rebase, reset and branch -f are routine for agents and the engine (setup-triage quarantine, the post-finish update-ref recovery, rebase), so a veto there would break legitimate builds. The track marker's scope boundary and the amended ADR record that exclusion. This waiver covers only that excluded class. It does not waive any story criterion, task check, or the coverage of outcomes 2 to 5.
