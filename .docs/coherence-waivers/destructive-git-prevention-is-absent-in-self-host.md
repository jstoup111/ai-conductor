Waives: outcome-2

Rationale: Outcome-2 asks that every limitation of the destructive-git prevention be explicitly documented. The limitations are absolute-path git, shell startup files that put another git earlier on PATH, shell aliases, interactive and inline runs with no prepared worktree, and custom providers; ADR adr-2026-09-23-engine-git-guard-on-agent-path decision 10 fixes the list. They belong in the control inventory in docs/reference/settings-and-hooks.md, which is ordinary project documentation that the stories and plan skills forbid carrying as stories or tasks. The operator chose on 2026-09-23 to route that edit to the documentation-maintenance step (the #2103 precedent), as architecture-review condition C5 records. This waiver covers only that documentation edit. It does not waive any story criterion, task check, or the mechanical coverage of outcomes 1 and 3–7.
