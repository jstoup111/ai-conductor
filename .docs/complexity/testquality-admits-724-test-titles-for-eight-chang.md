# Complexity: Accurate test-quality review scope

Tier: L

Comprehensive scope crosses frozen source assembly, test declaration and marker association, reviewer projections and anchor validation, cache identity, and ambiguous-scope handling. Correctness needs negative cases for shared setup, dynamic declarations, unsupported syntax, renames, duplicate titles, and unbound obligations. A smaller title filter would not satisfy the operator-approved breadth.

The existing configured test runner, aggregate suite, and provider dispatch remain the integration boundaries. No new external service or universal dependency-analysis platform is proposed.
