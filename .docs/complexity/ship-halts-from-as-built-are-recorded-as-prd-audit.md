# Complexity: SHIP halts from as-built are recorded as prd_audit, hiding them in metrics

Tier: S

Rationale: Rubric signals are all Small — no new model or table, no external integration, no auth, no new state machine, and five stories. The change is attribution plumbing inside existing machinery: the validation-group terminal halt sites in `conductor.ts` pass the member they already know into the existing `loop_halt` emission and halt-record write (an optional step on `writeHaltMarker` that `halt-marker.ts` prefers over the phase marker), the remediation-planner halt sites reuse the existing `recordGroupRefusal` member record, and the child executor's terminal outcome gains optional halt `step` and `haltClass` fields that the supervisor copies onto the `feature_dispatch_ended` event it already emits. No event union variant, persisted schema, CLI, hook, or settings contract changes; the executor protocol message passes the outcome object through unvalidated, so the optional fields are backward compatible in both directions without a protocol version bump. No APPROVED ADR is contradicted (adr-2026-08-23 D4 already requires the record to name the halting step; adr-2026-10-15 D4 already places dispatch events and the terminal outcome on the supervisor side).
